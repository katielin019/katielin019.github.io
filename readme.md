# katielin019.github.io

Mostly a "staging" site for little experiments and such. I used to do a similar thing with a subdomain of one of my sites, but I migrated web hosts and stopped using my own VPS, so it's more of a hassle to deploy stuff quickly.

I primarily use this to test out the responsiveness of my designs on mobile, but it's also helpful to stress test it outside my local dev environment.

For little one-off things, I'll probably just copy the HTML over and push the chnages so I don't have to make a whole new repo for it.

For stuff that's more involved, like my [positional grid](https://github.com/katielin019/positional-grid), I just make it into its own repo and then configure GitHub Pages for it. That way, any updates I make to it directly will get deployed without me having to touch this repo.
